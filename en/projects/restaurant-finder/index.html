DISCOVERY INTERFACE

Rest → Melbourne

A restaurant discovery interface, adapted from Istanbul to Melbourne.

FOCUS

Frontend development & adaptation

STATUS

Web demo

STACK

React / JavaScript / Python / Flask

01 / The problem

People look for places using location, cuisine, price and rating together. The interface needs to make those filters easy to combine.

02 / Technical approach

A shared discovery interface was adapted for Melbourne's areas and dining categories. The two versions are presented as one evolving project.

03 / Outcome & boundaries

Two demo variants of one product. Venue results depend on the data provider; the captured Melbourne screen may show an empty result state.
